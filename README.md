# НИРчек

Программа для студентов: проверяет оформление расчётно-пояснительной записки
(НИР, курсовая, ВКР) по ГОСТ 7.32-2017 и требованиям СТО МГТУ.

## Скачать

| Система | Файл | Что нужно |
|---|---|---|
| **Windows** | **[NirCheckSetup.exe: последняя версия](https://github.com/dyanch1kk/nirchek-releases/releases/latest/download/NirCheckSetup.exe)** | Windows 10 или 11 (64-бит), установленный Microsoft Word |
| **macOS** | **[NirCheck-mac-arm64.zip: последняя версия](https://github.com/dyanch1kk/nirchek-releases/releases/latest/download/NirCheck-mac-arm64.zip)** | Mac с чипом Apple (M1 и новее), macOS 15 или новее, установленный Microsoft Word для Mac. Mac с процессором Intel не поддерживаются |

Все версии и список изменений: [Releases](https://github.com/dyanch1kk/nirchek-releases/releases).

Word нужен, потому что через него программа делает предпросмотр документа.

## Установка на Windows

Порядок важен: **сначала снимите блокировку с файла, и только потом запускайте его.** Иначе Защитник Windows будет проверять файл при запуске, и установщик может открываться несколько минут.

1. Скачайте `NirCheckSetup.exe`. Если браузер пишет, что файл опасный или редкий, см. ниже, как его сохранить.
2. **Откройте PowerShell** (Пуск → введите `PowerShell` → Enter), вставьте команду и нажмите Enter. Она снимает с файла пометку «из интернета»:

   ```powershell
   Unblock-File -Path "$env:USERPROFILE\Downloads\NirCheckSetup.exe"
   ```

   Команда рассчитана на папку «Загрузки». Если файл лежит в другом месте, замените путь на свой. Если ошибки нет, команда ничего не выведет, это нормально.
3. **Запустите** `NirCheckSetup.exe` и следуйте подсказкам установщика. Права администратора не нужны. Программа появится в меню «Пуск».

Вместо PowerShell можно сделать то же мышкой: щёлкните файл правой кнопкой → **Свойства** → внизу поставьте галочку **Разблокировать** → OK. Если галочки нет, файл уже разблокирован.

### Если что-то пошло не так

**Браузер пишет «Заблокировано скачивание опасного файла» или «Файл редко скачивают».**
- Chrome: откройте список загрузок (значок со стрелкой вниз), рядом с файлом нажмите стрелку или «⋮» и выберите **Сохранить** (если нужно, ещё раз **Сохранить опасный файл**). Или откройте адрес `chrome://downloads`.
- Edge: рядом с файлом нажмите «⋯», затем **Сохранить** и **Всё равно сохранить**.

**Windows пишет «Система Windows защитила ваш компьютер».**
Вы запустили файл, не сняв блокировку. Нажмите **Подробнее**, затем **Выполнить в любом случае**. В следующий раз сначала выполните команду из шага 2.

**Установщик долго не открывается или проводник «зависает».**
Защитник Windows проверяет новый файл, это может занять несколько минут. Дождитесь окончания. Чтобы в следующий раз не ждать, выполните команду `Unblock-File` до запуска.

**Защитник Windows удалил файл или заблокировал запуск.**
Откройте «Безопасность Windows» → «Защита от вирусов и угроз» → «Журнал защиты», найдите запись про `NirCheckSetup.exe` и в «Действиях» выберите **Разрешить на устройстве**. Затем скачайте файл заново и снова выполните шаги 2 и 3. 
## Установка на macOS

Программа не подписана сертификатом Apple (тк он платный), поэтому при первом запуске macOS её заблокирует. Запуск нужно один раз подтвердить вручную.

1. Скачайте `NirCheck-mac-arm64.zip` **через браузер** (Safari или Chrome). Не пересылайте файл через Telegram и другие мессенджеры: macOS тогда блокирует программу полностью, и кнопки «Всё равно открыть» не будет.
2. Дважды щёлкните по zip-файлу: появится `NirCheck.app`. Перетащите её в папку **Программы**.
3. Дважды щёлкните по `NirCheck.app`. macOS скажет, что не может проверить разработчика. Закройте окно кнопкой «Готово» или «OK», не нажимая «Переместить в Корзину».
4. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз до раздела «Безопасность», рядом с «NirCheck» нажмите **Всё равно открыть**, введите пароль Mac  и подтвердите **Открыть**. Это только первый раз нужно, дальше программа открывается обычным двойным щелчком.

То же одной командой: откройте «Терминал», вставьте 
```
   xattr -dr com.apple.quarantine /Applications/NirCheck.app
   ```
и нажмите Enter, затем откройте программу двойным щелчком.

При первом предпросмотре macOS может спросить, можно ли программе управлять Microsoft Word. Нажмите **OK**. Если отказали: Системные настройки → Конфиденциальность и безопасность → **Автоматизация** → NirCheck → включите Microsoft Word.

### Если что-то пошло не так

**«Не удаётся открыть программу» с единственной кнопкой OK или «Программа повреждена».**
Обычно файл пришёл через мессенджер или распакован нестандартной программой. Скачайте архив заново через браузер, распакуйте двойным щелчком или выполните команду `xattr` из шага выше.

**Программа вообще не запускается.**
На Mac с процессором Intel и на macOS 14 и старше эта версия не работает.

## Где программа хранит файлы и как их удалить

Когда вы открываете работу, программа делает рабочие файлы на вашем компьютере. Студенческие работы никуда не отправляются.

### На Windows:

| Что | Где лежит | Сколько занимает |
|---|---|---|
| Служебные файлы открытых документов (превью PDF) | `%APPDATA%\NirCheck\projects` | около 1,5 МБ на документ; не открывавшиеся 30 дней удаляются сами |
| База работ: запись, копия .docx и .pdf работы | `%APPDATA%\NirCheck\works_db` | около 3 МБ на работу |
| Ваши профили оформления и последние папки | `%APPDATA%\NirCheck` | несколько КБ |
| Недавние работы, история проверок, выбор тире | `C:\Users\<имя>\.nir_recent.json`, `.nir_check_history.json`, `.nir_dash_preference.json` | несколько КБ |

Чтобы открыть папку, нажмите Win+R, введите `%APPDATA%\NirCheck` и нажмите Enter.

**Как удалить работу из базы:** вкладка «База работ» → отметьте галочкой → «Удалить».
**Как удалить всё:** при удалении программы («Параметры → Приложения → НИРчек») установщик спросит, удалять ли и данные программы. Ответьте «Да»: будут удалены база работ, профили, история и служебные файлы. Вручную: удалите папку `%APPDATA%\NirCheck` и три файла `.nir_*.json` из папки `C:\Users\<имя>`.

Копия работы лежит в базе, поэтому её можно открыть, даже если исходный файл вы уже удалили или переместили.

Если вы добавляете исправленную версию работы того же студента (тот же вид работы и год), программа спросит, заменить ли старую запись. При замене старая копия работы и её замечания удаляются.

### На Mac:

| Что | Где лежит |
|---|---|
| Служебные файлы, база работ, профили оформления | `~/Library/Application Support/NirCheck` (папки `projects` и `works_db`) |

Чтобы открыть папку: в Finder меню **Переход → Переход к папке…** (⇧⌘G), вставьте `~/Library/Application Support/NirCheck`. 


## Обновление

Чтобы обновиться, скачайте свежий установщик, снимите с него блокировку (команда `Unblock-File` или `xattr`), затем запустите и установите поверх. Ваши данные сохранятся.
